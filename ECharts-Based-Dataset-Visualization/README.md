# ECharts-Based Dataset Visualization

## 1. Project Introduction

This project is an information visualization experiment
based on automobile datasets.

The project includes data preprocessing, statistical
analysis, and interactive visualization using ECharts.

## 2. Technologies Used

- Python
- Pandas
- HTML
- CSS
- JavaScript
- Apache ECharts

## 3. Project Files

- prepare_automobile.py: Data preprocessing
- analyze_automobile.py: Statistical data analysis
- automobile_clean.csv: Cleaned automobile dataset
- index.html: Interactive visualization interface

## 4. Project Objectives

1. Understand the basic workflow of data visualization.
2. Perform data cleaning and preprocessing using Python.
3. Analyze automobile dataset characteristics.
4. Create interactive charts using ECharts.
5. Explore relationships between automobile attributes.

## 5. How to Run

1. Download the project files.
2. Install the required Python libraries.
3. Run prepare_automobile.py to preprocess the dataset.
4. Run analyze_automobile.py for statistical analysis.
5. Open index.html through a local web server to view the visualization.
