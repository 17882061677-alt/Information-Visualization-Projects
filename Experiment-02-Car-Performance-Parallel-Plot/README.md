# Experiment 02 - Interactive Data Visualization

## Project Introduction

This project is the second experiment of the Information
Visualization course.

The experiment focuses on interactive data visualization
using web technologies.

## Technologies Used

- HTML
- CSS
- JavaScript
- Data Visualization

## Project Structure

- index.html: Main webpage
- style.css: Webpage styles
- app.js: JavaScript logic and interactions
- data/: Dataset files

## How to Run

Open the project using a local web server
and access index.html in your browser.
